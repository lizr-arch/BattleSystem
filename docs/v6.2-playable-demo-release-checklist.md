# V6.2 Playable MVP Release Candidate — 发布检查清单

本文件面向开发者，用于 V6.2 可玩 Demo 发布候选版本的逐项验收。

---

## Release Checklist

1. `git checkout main && git pull`
2. `npm install`
3. `npm test`（必须 **PASS**）
4. `npm run audit:map`（必须 **PASS**）
5. `npm start` → 打开 `http://127.0.0.1:8000/index.html`
6. 点击 **"Start Demo Battle"**
7. 确认 **Player HUD** 显示 Goal / Controls / Player HP / Enemy HP
8. 确认 **Developer Diagnostics** 的 warnings 显示 `(none)`
9. 确认 **Trait Payoff** 可见（右侧 Debug Panel 的 "Last Trait Payoff"）
10. 确认按 **R（Reset）** 后 demo 仍保留
11. 确认可通过 **Arts** 击败 TrainingBrute（Victory path）
12. 确认敌人可击败玩家（Defeat path）
13. 确认无真实 `console.error`

---

## Smoke Checklist

1. `npm run smoke:demo-static`（必须 **PASS**）
2. `npm run smoke:demo-r-key`（**PASS**，或如实报告 Playwright 不可用）
3. `npm run smoke:demo-ui`（**PASS**，或如实报告 Playwright 不可用）

---

## 备注

- V6.2 **不新增**战斗机制
- **不实现** Chain Attack / Full Burst / Fusion Combo
- **不实现** Life Skill gameplay
