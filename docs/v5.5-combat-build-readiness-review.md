# V5.5 Combat Build Readiness Review（战斗构筑兑现预审）

> 状态：Design / Readiness Review  
> 目标：在不扩展生活玩法、不进入 Chain Attack / Full Burst / Fusion Combo 的前提下，审查当前 Backpack / Beast Blade / Bond / ElementCore / RoutineOrb 如何转化为明确的战斗构筑差异。  
> 结论：V5.5.1 推荐先实现 **Trust Unlock Combat Slot MVP（信任解锁战斗槽 MVP）**，只做数据层 unlock，不做完整技能系统。

---

## 1. 当前已完成能力

| 系统 | 已完成能力 | 可用于构筑的输入 | 当前不足 |
|---|---|---|---|
| Backpack（背包） | 9×9 网格；BladeItem 占格；最多 active 2 个 Blade；越界/重叠校验 | Blade 占地、位置、activeBlades 顺序 | 背包布局目前主要决定携带数量，还没有明显战斗 build payoff |
| BladeItem（异刃物品） | 可放入背包；可解析为 BladeRuntime；可拥有 internal equipment / socket | BladeId、role、autoAttackSpec、footprint | Blade 与内部 socket 的战斗用途仍偏基础 |
| ElementCore（元素核心） | 插入 socket 后赋予 element 与 damageBonus | element、damageBonus | 目前主要是属性名 + 伤害加成，缺少和物种/套路的差异化互动 |
| BeastBlade（兽型异刃） | Wolf / Bear / Tiger；lineage；rarity；hiddenProfile；lifeSkills | species、lineage、rarity、hiddenProfile | 物种已影响伤害/冷却，但还缺更明确的战斗构筑兑现 |
| IndividualTrait（个体特质） | Fierce / Loyal / Proud；Fierce 影响伤害；Loyal/Proud 影响 Bond 增长 | individualTrait | Loyal/Proud 还主要影响成长，不够直接改变战斗选择 |
| HiddenStatProfile（隐藏属性模板） | hp/damage/speed/cooldown/skillBudget | damageMultiplier、cooldownMultiplier 等 | hp/skillBudget 暂未进入真实战斗决策 |
| Bond（羁绊） | Trust / Mood / Sync；命中/胜利/失败影响 Bond；reset 语义明确 | trust、trustLevel、mood、sync | Trust 目前是成长值，还未解锁战斗能力 |
| RoutineOrb（套路球） | 技能成牌、成球、破球、Burn、Victory 闭环 | routineId、totalLayer、Burn、破球事件 | 尚未和 BeastBlade / Bond / ElementCore 形成轻量联动 |
| LifeSkills（生活技能） | LifeSkillTag + level；activeLifeSkills 合并 | Tracking / Hunting / Mining 等标签 | 本阶段只保留接口，不进入 V5.5 战斗主线 |

### 1.1 总体判断

当前 BattleSystem 已有“单人 + 敌人 + 异刃 + 背包 + 兽型差异 + 羁绊”的核心原型。问题不再是“有没有机制”，而是：

```text
这些机制如何让玩家产生不同构筑选择？
```

当前还缺一个轻量的 combat payoff（战斗兑现）层，把 Trust / Trait / ElementCore / RoutineOrb 逐步接到战斗决策上。

---

## 2. 当前构筑问题

### 2.1 Trust 只是成长值，还不是战斗选择

Trust 已经会增长，也会跨 reset 保留。但目前它主要是数字：

```text
BladeAttackHit / Victory
  ↓
Trust 增长
```

还没有形成：

```text
Trust 达到某等级
  ↓
解锁一个战斗构筑能力
```

因此玩家还没有强理由长期培养某个异刃。

### 2.2 Trait 差异仍不够“战斗化”

当前：

- Fierce：直接提高伤害，战斗存在感强。
- Loyal：主要让 Trust 增长更多。
- Proud：Trust 增长较少，Sync 增长更多。

Loyal / Proud 已经有成长逻辑，但还不够像“战斗性格”。

### 2.3 ElementCore 还只是属性和伤害加成

ElementCore 当前负责：

```text
element
damageBonus
```

这很好，因为元素不应来自 species。但战斗上它还缺少“不同物种使用同一元素会有不同味道”的感觉。

### 2.4 RoutineOrb 仍是单人闭环

RoutineOrb 已有完整 MVP，但还没有和异刃产生轻量联动：

```text
破球
  ↓
异刃是否回应？
羁绊是否增长？
某个 trait 是否更容易追加？
```

### 2.5 LifeSkills 应保持低优先级

LifeSkills 只作为探索/生活接口保留。当前主线是战斗系统，V5.5 不应转去做采集、狩猎、挖矿。

---

## 3. 候选兑现方向

## A. Trust Unlock（信任解锁）

| Trust Level | 候选效果 | 说明 |
|---:|---|---|
| Lv2 | 小幅提高 Sync gain | 有感但容易变成纯数值 |
| Lv3 | 解锁 BondCombatSlot1 | 建议作为 V5.5.1 最小实现 |
| Lv4 | 解锁 trait upgrade | 需要 trait 系统更成熟 |
| Lv5 | 解锁 Bond Assist | 接近更大玩法，应延后 |

V5.5.1 不应一口气做完所有等级。推荐只做：

```text
Trust Lv3
  ↓
resolvedBlade.unlocks.combatSlots = ['BondCombatSlot1']
```

这个 unlock 暂时不消费，不装备技能，不改变伤害，只作为后续技能/槽位系统的安全入口。

### 为什么选 combat slot？

因为直接加伤害会把 Trust 简化成数值成长。CombatSlot 是“构筑空间”的成长，后续可以承接技能、特质强化、元素联动等内容。

---

## B. Trait Combat Payoff（个体特质战斗兑现）

| Trait | 候选战斗兑现 | 当前状态 | V5.5 建议 |
|---|---|---|---|
| Loyal | 保护主角、失败前援护、Victory 后 Trust 更多 | Trust 增长更多 | 先不做护主行为，保留到后续 |
| Fierce | 高伤害、追击、破球后追加 | 伤害 x1.1 | 可在 V5.5.2 做破球后追加伤害 |
| Proud | 低 Trust 增长、高 Sync 增长、高 Trust 后更强 | Sync 更多、Trust 较少 | 可在高 Trust 后强化 |
| Protective | 主角低血保护 | 未实现 | 不进入 V5.5.1 |
| Cautious | 低血保守、防御倾向 | 未实现 | 不进入 V5.5.1 |

V5.5.1 不做复杂行为树。Trait payoff 必须是 deterministic modifier（确定性修正）。

---

## C. ElementCore + Beast Species Interaction（元素核心 + 物种交互）

| 组合 | 候选方向 |
|---|---|
| FireCore + Wolf | 追击 / 流血倾向 |
| FireCore + Bear | 重击 / 破防倾向 |
| FireCore + Tiger | 爆发倾向 |
| Neutral + any | 无特殊联动 |

关键规则：

```text
Element 仍来自 ElementCore，不来自 species。
Species 只决定如何使用元素，不决定元素本身。
```

不建议 V5.5.1 先做元素物种互动，因为它会同时牵涉元素表、物种表、状态规则、UI 和未来平衡。建议放到 V5.5.3。

---

## D. RoutineOrb + Bond / Blade Interaction（套路球 + 羁绊 / 异刃联动）

| 触发点 | 候选效果 |
|---|---|
| RoutineOrbBroken | active Blade 增加 Sync |
| RoutineOrbBroken + high Sync | Blade 追加轻量攻击 |
| RoutineOrbBroken + Loyal | 获得临时防御收益 |
| RoutineOrbBroken + Fierce | 获得追加伤害 |
| RoutineOrbBroken + Proud | 更高 Sync gain |

这不是 Chain Attack / Full Burst / Fusion Combo。它只是 RoutineOrb MVP 的轻量后续。

不建议 V5.5.1 先做。先有 Trust unlock 的数据通道，再接 RoutineOrb assist。

---

## 4. 推荐优先级

| 优先级 | 里程碑 | 目标 | 原因 |
|---:|---|---|---|
| 1 | V5.5.1 Trust Unlock Combat Slot MVP | Trust Lv3 解锁 `BondCombatSlot1` | 建立“长期养成 → 构筑空间”的最小通路 |
| 2 | V5.5.2 Trait Combat Payoff MVP | Loyal/Fierce/Proud 获得更明确战斗兑现 | 让个体特质不只是成长修正 |
| 3 | V5.5.3 ElementCore + Species Interaction MVP | 同一元素在不同物种上有不同战斗味道 | 强化构筑组合 |
| 4 | V5.5.4 RoutineOrb + Bond Assist MVP | 破球后触发轻量 Bond/Blade 追加 | 接近高级 payoff，需谨慎推进 |

### 为什么不是先做 Chain Attack / Full Burst / Fusion Combo？

因为当前已有机制还没有被充分兑现。贸然进入 Chain Attack / Full Burst 会把系统推向更大结算层，但基础构筑差异还不够清晰。

---

## 5. V5.5.1 推荐实现范围

推荐 V5.5.1 只实现：

```text
Trust Lv3
  ↓
resolvedBlade.unlocks.combatSlots = ['BondCombatSlot1']
```

### 为什么推荐 combatSlots，而不是 traitBoosts？

`traitBoosts` 会立刻牵涉具体 trait 行为，而 trait 系统还不够稳定。`combatSlots` 是更安全的结构入口：

- 不直接改变数值。
- 不要求完整技能系统。
- 后续可以接技能槽、被动槽、强化槽。
- 更符合“羁绊解锁构筑空间”的设计目标。

### V5.5.1 最小数据结构

```js
resolvedBlade.unlocks = {
  combatSlots: [],
  traitBoosts: []
}
```

Trust Lv3 后：

```js
resolvedBlade.unlocks.combatSlots = ['BondCombatSlot1']
```

### V5.5.1 不消费 unlock

V5.5.1 只证明 unlock 出现，不做：

- 技能装备
- socket UI
- 新技能释放
- 新伤害公式
- trait 强化
- 元素互动

---

## 6. V5.5.1 不做内容

V5.5.1 不做：

- Life Skill gameplay
- 采集 / 狩猎 / 挖矿
- 送礼 / 喂食
- 羁绊剧情
- 多异刃好感竞争
- 异刃离队
- 完整技能系统
- 完整 socket UI
- Trait upgrade 实装
- ElementCore + Species interaction
- RoutineOrb + Bond Assist
- Chain Attack
- Full Burst
- Fusion Combo

## 7. V5.5.1 验收建议

| Case | 期望 |
|---|---|
| Trust Lv1 | `unlocks.combatSlots` 为空 |
| Trust Lv3 | `unlocks.combatSlots` 包含 `BondCombatSlot1` |
| resetRuntime 后 | Trust 保留，因此 unlock 保留 |
| Defeat 后 | Trust 不下降，因此 unlock 不丢 |
| DebugPanel | 能显示 unlocks |
| V5.4 回归 | Bond tests/scenarios 不回归 |

推荐 scenarios：

```text
trust-lv1-no-combat-slot
trust-lv3-unlocks-combat-slot
trust-unlock-survives-reset
trust-unlock-survives-defeat
```

---

## 8. 最终结论

V5.5 不应该先做生活技能，也不应该先做 Chain Attack / Full Burst / Fusion Combo。

推荐先做：

```text
V5.5.1 Trust Unlock Combat Slot MVP
```

它是一个小而关键的连接点：

```text
Bond Trust（长期养成）
  ↓
Combat Unlock（战斗构筑空间）
  ↓
后续 skill / trait / element / routine payoff 的入口
```
