# V5.1 Backpack Blade MVP SPEC（背包异刃最小实现规格）

本文是 V5.1 的开发规格。V5.1 目标是实现最小 Backpack（背包）+ Blade（异刃）+ Nested Socket（嵌套槽位）+ Blade auto attack（异刃自动攻击）闭环。

## 1. 目标闭环

```text
Driver Backpack（9×9 背包）
  ↓
放入 BladeItem（异刃物品）
  ↓
Blade 内部 SlotModule（槽位扩展装备）生成 1×1 socket
  ↓
socket 插入 ElementCore（元素核心）
  ↓
LoadoutResolver（构筑解析器）输出 activeBlades
  ↓
CombatActor 创建 BladeRuntime（异刃战斗单位）
  ↓
Blade 自动攻击目标
  ↓
BladeAttackHit element=Fire
  ↓
DamageApplied / TargetHpChanged
```

## 2. 建议新增 core 文件

```text
src/core/backpack-grid.js
src/core/backpack-items.js
src/core/loadout-resolver.js
src/core/blade-runtime.js
```

`src/core` 不得依赖 DOM / Canvas / window / document。

## 3. BackpackGrid

实现 9×9 背包：

- 物品不越界。
- 物品不重叠。
- 找出已放置 BladeItem。
- MVP 只支持矩形物品，不支持旋转。

## 4. MVP ItemDefinition

至少定义：

- CrimsonBlade：DPS（输出）异刃，3×3。
- GuardianBlade：Tank（肉）异刃，3×3。
- SmallSocketModule：生成一个 1×1 socket。
- FireCore：ElementCore，提供 element=Fire、damageBonus=0.1。

Blade 本体不自带 element。

## 5. Nested Socket 规则

- SlotModule 在 Blade footprint 内生成 socket。
- socket 不能越出 Blade footprint。
- V5.1 只实现 1×1 socket。
- socket 只接受 ElementCore。
- 插入 FireCore 后 resolvedBlade.element = Fire。
- 未插 Core 时 resolvedBlade.element = Neutral。

## 6. LoadoutResolver

输出：

```text
resolvedLoadout.activeBlades[]
resolvedLoadout.errors[]
```

规则：

- 背包合法才输出 activeBlades。
- 按扫描顺序最多激活 2 个 Blade。
- Blade 本体不自带 element。
- element 来源于 socket 内 ElementCore。
- socket 越界必须失败并返回 BackpackInvalid。

## 7. BladeRuntime

CombatActor 应持有：

```text
bladeRuntimes[]
```

每个 BladeRuntime 至少包含：

```text
bladeInstanceId
bladeId
role
element
state
action
cooldownLeft
autoAttackSpec
```

Blade 自动攻击规则：

- battle.active === false 时不更新。
- target.dead 时不更新。
- target 在 range 内且 cooldown 为 0 时开始攻击。
- 攻击使用 Startup / Active / Recovery / Cooldown。
- Active 命中帧检查距离。
- 命中产生 BladeAttackHit。
- 打空产生 BladeAttackWhiffed。

V5.1 中 Blade 跟随 Driver，不拥有独立位置；攻击距离使用 Driver position。

## 12. 不做内容

V5.1 禁止实现：

- 拖拽 UI。
- 物品旋转。
- 复杂形状。
- 背包商店 / 掉落。
- Blade 独立寻路。
- Blade 复杂 AI。
- Blade 自己挂 RoutineOrb。
- Chain Attack。
- Full Burst。
- Fusion Combo。
