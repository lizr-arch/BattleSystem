# V5.1 Backpack Blade MVP SPEC（背包异刃最小实现规格）

> 本文是 V5.1 的开发规格。V5.1 目标是实现最小 Backpack（背包）+ Blade（异刃）+ Nested Socket（嵌套槽位）+ Blade auto attack（异刃自动攻击）闭环。

## 1. 前置条件

实现前必须确认：

- V4.3 已合并到 main。
- `npm test` PASS。
- `npm run audit:map` PASS。
- 已阅读：
  - `docs/v5-backpack-blade-index.md`
  - `docs/backpack-loadout-design.md`
  - `docs/blade-nested-socket-design.md`

## 2. 目标闭环

```text
Driver Backpack（9×9 背包）
  ↓
放入 BladeItem（异刃物品）
  ↓
Blade 内部 SlotModule（槽位扩展装备）生成 1×1 socket
  ↓
socket 插入 ElementCore（元素核心）
  ↓
LoadoutResolver（构筑解析器）输出 activeBlades
  ↓
CombatActor 创建 BladeRuntime（异刃战斗单位）
  ↓
Blade 自动攻击目标
  ↓
BladeAttackHit element=Fire
  ↓
DamageApplied / TargetHpChanged
```

## 3. 建议新增 core 文件

```text
src/core/backpack-grid.js
src/core/backpack-items.js
src/core/loadout-resolver.js
src/core/blade-runtime.js
```

要求：`src/core` 不依赖 DOM / Canvas / window / document。

## 4. BackpackGrid（背包网格）

实现 9×9 背包，支持：

- 物品不越界。
- 物品不重叠。
- 找出已放置 BladeItem（异刃物品）。

MVP 只支持矩形物品，不支持旋转。

## 5. MVP ItemDefinition（物品定义）

至少定义：

- `CrimsonBlade`：DPS（输出）异刃，3×3。
- `GuardianBlade`：Tank（肉）异刃，3×3。
- `SmallSocketModule`：生成一个 1×1 socket，位置在 Blade footprint（异刃占地）内。
- `FireCore`：ElementCore（元素核心），提供 `element=Fire`、`damageBonus=0.1`。

Blade 本体不自带 element（属性）。

## 6. Nested Socket（嵌套槽位）规则

- SlotModule 在 Blade footprint 内生成 socket。
- socket 不能越出 Blade footprint。
- V5.1 只实现 1×1 socket。
- socket 只接受 `ElementCore`。
- 插入 FireCore 后 `resolvedBlade.element = Fire`。
- 未插 Core 时 `resolvedBlade.element = Neutral`。

## 7. LoadoutResolver（构筑解析器）

输入：

```text
backpackGrid
itemDefinitions
bladeInternalEquipment
socketAssignments
```

输出：

```text
resolvedLoadout.activeBlades[]
resolvedLoadout.errors[]
```

规则：

- 背包合法才输出 activeBlades。
- 按扫描顺序最多激活 2 个 Blade。
- Blade 本体不自带 element。
- element 来源于 socket 内 ElementCore。

## 8. BladeRuntime（异刃战斗单位）

CombatActor 应持有：

```text
bladeRuntimes[]
```

每个 BladeRuntime 至少包含：

```text
bladeInstanceId
bladeId
role
element
state
action
cooldownLeft
autoAttackSpec
```

Blade 自动攻击规则：

- `battle.active === false` 时不更新。
- `target.dead` 时不更新。
- target 在 range 内且 cooldown 为 0 时开始攻击。
- 攻击使用 Startup / Active / Recovery / Cooldown（前摇 / 命中段 / 后摇 / 冷却）。
- Active 命中帧检查距离。
- 命中产生 `BladeAttackHit`。
- 打空产生 `BladeAttackWhiffed`。

## 9. 必须新增事件

新增 CombatEventType（战斗事件枚举）：

- BackpackResolved（背包构筑解析完成）
- BackpackInvalid（背包构筑非法）
- BladeLinked（异刃进入战斗）
- BladeAttackStarted（异刃攻击开始）
- BladeAttackPhaseChanged（异刃攻击阶段变化）
- BladeAttackHit（异刃攻击命中）
- BladeAttackWhiffed（异刃攻击打空）
- BladeAttackFinished（异刃攻击结束）
- BladeAttackCooldownStarted（异刃攻击冷却开始）
- BladeAttackCooldownFinished（异刃攻击冷却结束）
- BladeSocketResolved（异刃槽位解析完成）

所有事件必须在 `combat-events.js` 里格式化。

```text
bladeRuntimes
```

UI 和 scenarios 只读 snapshot。

## 12. Tests（测试）

新增：

```text
tests/backpack-grid.test.mjs
tests/loadout-resolver.test.mjs
tests/blade-runtime.test.mjs
tests/backpack-blade-scenario.test.mjs
```

并加入 `npm test`。

必须覆盖：

- 9×9 背包创建。
- Blade 3×3 合法放置。
- Blade 越界失败。
- Blade 重叠失败。

- socket 越界失败。
- FireCore 插入 socket 后 resolvedBlade.element=Fire。

- 多 Blade 时最多 active 2 个。
- BladeAttackHit 造成 DamageApplied / TargetHpChanged。
- V4.3 测试不回归。

## 13. UI / Canvas

V5.1 UI 只做最小可观察性，不做拖拽。

DebugPanel 新增：

- Backpack size（背包尺寸）。
- Active Blades（激活异刃列表）。
- Blade element（异刃属性）。
- Blade role（异刃定位）。
- Blade action / cooldown。
- Last Blade Event（最近异刃事件）。

按钮：

- Run Backpack Blade MVP
- Run Blade Fire Core
- Run Multiple Blades Limit

Canvas：显示 BladeRuntime 小标记与 BladeAttackHit / BladeAttackWhiffed 轻量提示。
