## V5.3：Beast Blade Archetype MVP（未来）

### 目标

实现兽型异刃的最小原型，使异刃从"装备插件"变为"有物种/品系/特质的动物伙伴"。

### 建议实现范围

1. **物种实现**：Wolf（狼）、Bear（熊）、Tiger（虎）三种物种
2. **品系实现**：每种 1-2 个品系（如 GreyWolf + MoonWolf, BrownBear, BengalTiger）
3. **隐藏属性**：HiddenStatProfile 影响 BladeRuntime 的 hp/damage/speed/cooldown/skillBudget
4. **个体特质**：IndividualTraits 影响简单行为触发（如 Loyal→护主概率提升、Fierce→攻击频率提升）
5. **LifeSkills**：LifeSkillTag + LifeSkillLevel 出现在 resolvedLoadout 中（只做数据存在，不消费）
6. **Element 关系**：element 仍来自 ElementCore，不来自 species

### 核心数据结构新增

- `BeastBladeSpecies` 枚举/配置（Wolf/Bear/Tiger/...）
- `BeastBladeLineage` 枚举/配置（GreyWolf/SnowWolf/RedWolf/MoonWolf/...）
- `BeastBladeRarity` 枚举（Common/Uncommon/Rare/Legendary）
- `IndividualTrait` 枚举（Loyal/Fierce/Cautious/Proud/Glutton/Protective）
- `HiddenStatProfile` 数据结构（hpMultiplier/damageMultiplier/speedMultiplier/cooldownMultiplier/skillBudget）
- `LifeSkillEntry` 和 `LifeSkillTag` 枚举（15 种标签）

### 修改点

- `src/core/backpack-items.js`：BladeItem 新增 species/lineage/rarity/individualTrait/hiddenProfile/lifeSkills 字段
- `src/core/loadout-resolver.js`：resolvedLoadout 新增物种信息和 activeLifeSkills
- `src/core/blade-runtime.js`：BladeRuntime 读取 hiddenProfile 调整攻击参数，读取 individualTrait 影响行为

### 新增事件（建议）

- `BladeSpeciesResolved`：物种/品系解析完成
- `BladeTraitActivated`：个体特质触发

### 不做

- 不做羁绊系统（Trust/Mood/Sync 代码实现）
- 不做生活技能消费逻辑
- 不做养成/升级/进化系统
- 不做完整 UI 展示（Debug 面板可显示，不做正式玩家 UI）

## V5.4：Bond System MVP（未来）

### 目标

实现羁绊三维度的最小原型。

### 建议实现范围

1. **Trust**：5 级信任等级，战斗参与和胜利驱动增长
2. **Mood**：0-100 短期心情，战斗事件驱动波动
3. **Sync**：0-100 即时配合度，协同事件驱动累积与衰减
4. **战斗事件驱动**：异刃命中/护主/Driver 取消窗口等事件提升 Sync
5. **羁绊等级解锁**：Trust 达到特定等级解锁 socket 或技能

### 核心数据结构新增

- `BondState` 数据结构（trustLevel/mood/sync）
- `BondConfig` 配置（Trust 等级阈值、Mood 变化幅度、Sync 衰减速度等）

### 修改点

- `src/core/blade-runtime.js`：BladeRuntime 内部新增 BondState，每帧 tick Bond 衰减、Mood 恢复等
- `src/core/combat-actor.js`：在相关战斗事件发生时更新 Bond 值（如 BladeHit→Sync 增长）
- `src/core/loadout-resolver.js`：根据 Trust 等级确定可用技能和 socket

### 新增事件（建议）

- `BondTrustChanged`：Trust 等级变化
- `BondMoodChanged`：Mood 变化
- `BondSyncTriggered`：Sync 达到阈值触发
- `BondAssistActivated`：协同技释放
- `BondSkillUnlocked`：羁绊等级解锁新技能
- `BondSocketUnlocked`：羁绊等级解锁新 socket
- `BondMilestoneReached`：达到关键里程碑

### 不做

- 不做可消耗礼物系统
- 不做喂食/食物偏好系统
- 不做多异刃好感竞争
- 不做羁绊下降导致异刃离队
- 不做复杂动画和 UI

## 与现有系统的关系

- **BladeRuntime**：V5.3 读取物种属性影响战斗；V5.4 读取 Bond 影响行为
- **LoadoutResolver**：V5.3 解析物种/品系/特质；V5.4 解析 Trust 决定的可用技能；V5.5 解析 LifeSkills
- **CombatEventLog**：所有新事件均通过 CombatEventLog 记录
- **BackpackGrid / BackpackItems**：BladeItem 数据结构扩展（不改变网格逻辑）
- **UI / Debug Panel**：逐步在 Debug 面板中展示新数据

## 风险与约束

- 数据结构扩展不能破坏现有 V5.1 的测试和 scenario
- 所有新数据必须通过 resolvedLoadout 暴露，不能绕过 LoadoutResolver 直接读取
- Element 来源不变（ElementCore），不能因物种设计而混淆此规则
- 隐藏属性不可在普通 UI 暴露完整数值
- 羁绊改变行为而非纯数值加成
