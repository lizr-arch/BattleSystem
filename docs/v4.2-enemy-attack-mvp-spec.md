# V4.2 Enemy Attack MVP Implementation SPEC（敌人攻击最小实现规格）

> 本文是 V4.2 的开发规格。V4.1 只提交设计，不实现功能。

## 1. Goal（目标）

把敌人从 Dummy（木桩目标）升级为 Simple Enemy（简单敌人）：

```text
敌人在范围内
  ↓
发动 EnemyStrike（敌人普通攻击）
  ↓
Startup（前摇）
  ↓
Active（命中段）
  ↓
玩家受到伤害
  ↓
玩家可能 Defeat（失败）
```

## 2. Must Implement（必须实现）

### EnemyAttackSpec（敌人攻击配置）

- id: EnemyStrike
- startupFrames: 30
- activeFrames: 4
- recoveryFrames: 30
- cooldownFrames: 90
- damage: 15
- range: 140

### Enemy Runtime State（敌人运行时状态）

V4.2 可以先作为 CombatActor（战斗角色）的 enemy 子对象实现：

- id
- hp / maxHp / dead
- x / y
- state
- currentAction
- cooldownLeft
- targetId: Player

### Player Damage（玩家受伤）

新增链路：

```text
EnemyAttackHit（敌人攻击命中）
  ↓
PlayerDamageApplied（玩家受到伤害）
  ↓
PlayerHpChanged（玩家生命变化）
  ↓
PlayerDefeated（玩家被击败）
  ↓
BattleEnded Defeat（战斗失败）
```

### Enemy Tick（敌人每帧更新）

规则：

- 敌人死亡：不更新。
- 玩家死亡：不更新。
- Topple（倒地）/ Launch（浮空）：敌人不能攻击。
- currentAction 存在：推进动作时间轴。
- cooldownLeft > 0：减少冷却。
- 玩家在 range 内：开始 EnemyStrike。
- 玩家不在 range 内：Idle（待机）。

## 3. Events（事件）

V4.2 实现时加入 CombatEventType（战斗事件枚举）：

- EnemyTargetSelected（敌人选择目标）
- EnemyAttackStarted（敌人攻击开始）
- EnemyAttackPhaseChanged（敌人攻击阶段变化）
- EnemyAttackHit（敌人攻击命中）
- EnemyAttackWhiffed（敌人攻击打空）
- EnemyAttackFinished（敌人攻击结束）
- EnemyAttackCooldownStarted（敌人攻击冷却开始）
- EnemyAttackCooldownFinished（敌人攻击冷却结束）
- PlayerDamageApplied（玩家受到伤害）
- PlayerHpChanged（玩家生命变化）
- PlayerDefeated（玩家被击败）
- EnemyControlled（敌人被控制，可选）

所有事件必须走 typed formatter（类型化事件格式化）。

## 4. Snapshot（状态快照）

CombatActor.getSnapshot() 新增：

- enemy: id, hp, maxHp, dead, state, position, targetId, currentAction, cooldownLeft
- player: hp, maxHp, dead
- battle: active, result

UI（界面）和 Scenario Runner（脚本化场景运行器）只读 Snapshot（状态快照）。

## 5. Scenarios（脚本化场景）

新增：

- enemy-starts-attack-when-player-in-range
- enemy-attack-hits-player
- enemy-attack-whiffs-when-player-out-of-range
- enemy-attack-enters-cooldown
- enemy-cannot-attack-while-toppled
- enemy-can-defeat-player
- player-can-defeat-attacking-enemy

## 6. Tests（测试）

新增：

- tests/enemy-attack.test.mjs
- tests/enemy-attack-scenario.test.mjs
- tests/player-defeat.test.mjs

加入 npm test。

## 7. UI / Canvas（界面 / 画布）

DebugPanel（调试面板）新增：Enemy State（敌人状态）、Enemy Action（敌人动作）、Enemy Phase（敌人阶段）、Enemy Cooldown（敌人冷却）、Player HP（玩家生命值）、Last Enemy Event（最近敌人事件）。

Canvas（画布）显示：ENEMY WINDUP（敌人前摇）、HIT（命中）、MISS（打空）、DEFEAT（失败）。

## 8. Non-goals（不做内容）

V4.2 禁止实现：复杂行为树、寻路、多敌人、队友 AI、完整 Aggro（仇恨）系统、治疗/坦克职责、Chain Attack（连锁攻击阶段）、Full Burst（最终爆发）、Fusion Combo（融合连击）。

## 9. Acceptance（验收标准）

- npm test PASS
- npm run audit:map PASS
- enemy attack scenarios PASS
- 玩家会掉血
- 玩家能失败
- 敌人攻击有前摇/命中段/后摇/冷却
- 敌人倒地/浮空时不能攻击
- V4.0 Routine-Orb（套路挂球）旧测试不回归
- UI 能显示 Enemy / Player / Defeat 状态
- 未实现复杂 AI / Chain Attack / Full Burst / Fusion
