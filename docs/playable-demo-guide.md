# BattleSystem Demo Battle — 操作指南

## 启动方式

```bash
npm install && npm start
```

打开浏览器访问 `http://127.0.0.1:8000/index.html`。

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 1 / 2 / 3 / 4 | Arts（武技） |
| R | Reset Demo（重置演示） |
| Space | Pause（暂停） |

## Demo 目标

击败 **TrainingBrute** 即可获胜。

## 当前可体验机制

- 玩家移动
- Arts（武技）
- 敌方攻击
- Beast Blade（GreyWolf + BrownBear）
- FireCore
- Bond Lv3
- BondCombatSlot1
- FierceFollowUp
- LoyalGuard
- Victory / Defeat / Reset

## 当前不做

- Chain Attack
- Full Burst
- Fusion Combo
- Life Skill gameplay
- 背包拖拽 UI
- 完整技能系统

## 提示

右侧 Debug Panel 会实时展示详细战斗信息（事件日志、状态数值、机制触发等），建议打开观察。
