# V5.5.1 Trust Unlock Combat Slot MVP SPEC（信任解锁战斗槽最小实现规格）

> 状态：Draft SPEC  
> 前置：V5.5.0 Combat Build Readiness Review 通过后执行。  
> 目标：实现 Trust Lv3 解锁一个数据层 combat slot，不实现完整技能系统。

---

## 1. 目标

实现最小链路：

```text
Blade bond.trustLevel
  ↓
resolveCombatUnlocks()
  ↓
resolvedBlade.unlocks.combatSlots
  ↓
BladeRuntime snapshot
  ↓
DebugPanel 展示
```

V5.5.1 只证明：

```text
Trust Lv3 会解锁一个战斗构筑槽
```

不消费该槽，不装备技能，不改变伤害。

## 3. 推荐数据结构

新增或扩展：

```js
resolvedBlade.unlocks = {
  combatSlots: [],
  traitBoosts: []
}
```

Trust Lv1 / Lv2：

```js
unlocks.combatSlots = []
```

Trust Lv3+：

```js
unlocks.combatSlots = ['BondCombatSlot1']
```

V5.5.1 只处理 `combatSlots`，`traitBoosts` 保留为空。

---

## 4. 推荐新增 core 文件

可新增：

```text
src/core/combat-unlocks.js
```

建议 API：

```js
export function resolveCombatUnlocks({ bond } = {}) {
  const trustLevel = bond?.trustLevel ?? 1;
  const unlocks = {
    combatSlots: [],
    traitBoosts: [],
  };

  if (trustLevel >= 3) {
    unlocks.combatSlots.push('BondCombatSlot1');
  }

  return unlocks;
}
```

---

## 5. LoadoutResolver 集成

修改 `src/core/loadout-resolver.js`：

- resolvedBlade 默认包含 `unlocks` 字段。
- 如果 `resolvedBlade.bond` 存在，则根据 bond.trustLevel 解析 unlocks。
- 如果不存在 bond，则 unlocks 为空。

最小路径：

```text
resolvedBlade.bond
  ↓
resolveCombatUnlocks({ bond: resolvedBlade.bond })
  ↓
resolvedBlade.unlocks
```

---

## 6. CombatActor 集成

由于 V5.4.1 已经将 Bond 写回 `resolvedLoadout.activeBlades[].bond`，V5.5.1 应在以下位置重算 unlocks：

1. `commitBladeBondStates()` 写回 bond 后。
2. `resetRuntime()` 重新 linkBlade 前或 commit 后。
3. Victory / Defeat 后 commit 时。

建议新增：

```js
refreshBladeUnlocks()
```

语义：

- 遍历 `resolvedLoadout.activeBlades`
- 根据 `blade.bond` 调用 `resolveCombatUnlocks()`
- 写入 `blade.unlocks`

## 9. Scenarios

新增：

```text
trust-lv1-no-combat-slot
trust-lv3-unlocks-combat-slot
trust-unlock-survives-reset
trust-unlock-survives-defeat
```

### trust-lv1-no-combat-slot

期望：

- activeBlade.bond.trustLevel = 1
- activeBlade.unlocks.combatSlots 为空

### trust-lv3-unlocks-combat-slot

期望：

- 设置或累积 trust 到 Lv3
- activeBlade.unlocks.combatSlots 包含 `BondCombatSlot1`

### trust-unlock-survives-reset

期望：

- Trust Lv3
- resetRuntime()
- Trust 保留
- unlocks.combatSlots 仍包含 `BondCombatSlot1`

### trust-unlock-survives-defeat

期望：

- Trust Lv3
- Defeat
- Trust 不下降
- unlocks 不丢
